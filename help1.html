如何制作 工作图

  1. 建立新节点： 先点击 母节点，然后再按 “add” 按钮。
  2. 连接两个节点： 按着 Ctrl 键，按着滑鼠按钮，从 node① 拉到 node②.
  3. 更改 节点的资料： 直接在左边视窗里填写。
  4. 删除 节点或链结： 先选择节点或链结，按 “Delete” 键。

Creating a Project Graph

  1. Create new node: click on the parent node first, then click "add".
  2. Link 2 nodes: hold down Ctrl key, click on node① and drag to node②.
  3. Change node details: just fill in the form on the left.
  4. Delete node or link: select the node or link, then press "Delete" key.
